# Awesome Design (DESIGN.md)

68 ready-made DESIGN.md design-system files modeled on real brands. Drop one in, scaffold a whole UI from its exact tokens (colors, fonts, spacing, motion). Use instead of the stock frontend-design skill when you want a specific look.

## How to use
1. Pick a brand whose aesthetic fits the project (e.g. "build me a dashboard like Linear").
2. Pull that brand's DESIGN.md from the repo.
3. Feed it as the design spec; generate components against its tokens.

## When to reach for it
- "Make it look like Stripe / Vercel / Superhuman."
- Default AI frontend output feels samey and you want grounded tokens.
- You want a portable design spec to reuse across projects.

https://github.com/VoltAgent/awesome-claude-design  — browse the brand list in its README, each links a DESIGN.md.
